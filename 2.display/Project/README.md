# DC32480S035 屏端工程说明

这个工程已经写入 Codex 额度看板页面和 UART 接收脚本：

- `Screen0.tft`：320x480 竖屏 UI。
- `main.lua`：自由串口协议解析，接收 ESP32 的 `$CQ;...#` 帧并刷新控件。

## 显示内容

- 5 小时剩余额度大数字。
- 5 小时已用、倒计时、重置时间。
- 7 天剩余、已用、倒计时、重置时间。
- 7 天日均消耗速率。
- 额度已用 / 时间已过 / 安全上限三条条形进度。
- 红、黄、绿状态点。
- 本次更新时间和 ESP32 IP。

## 通信设置

Lua 中已经开启：

```lua
uart_free_protocol = 1
uart_set_timeout(0, 0)
```

ESP32 默认使用：

```text
UART2 TX GPIO17 -> 屏 RX
UART2 RX GPIO16 -> 屏 TX
115200 8N1
```

请在 VisualTFT 工程设置里确认串口波特率与 ESP32 一致。若你想换波特率，只需要同时修改：

- `firmware/esp32-codex-quota-display/esp32-codex-quota-display.ino` 的 `SCREEN_BAUD`
- VisualTFT 工程的串口波特率

## UART 帧格式

ESP32 每 60 秒发送一帧：

```text
$CQ;PR=87;PU=13;PCT=2h 11m;PRT=06/19 06:37;SR=74;SU=26;SCT=5d 8h;SRT=06/25 10:28;TP=21;SAFE=29;DR=17.8;R5=0;R7=1;RISK=1;PLAN=prolite;UP=06/19 02:16;IP=192.168.1.23#
```

字段：

| 字段 | 含义 |
| --- | --- |
| `PR` / `PU` | 5 小时剩余/已用百分比 |
| `PCT` / `PRT` | 5 小时倒计时/重置时间 |
| `SR` / `SU` | 7 天剩余/已用百分比 |
| `SCT` / `SRT` | 7 天倒计时/重置时间 |
| `TP` | 7 天窗口时间已过百分比 |
| `SAFE` | 按每天 20% 计算的当前安全上限 |
| `DR` | 日均消耗速率 |
| `R5` / `R7` | 5 小时/7 天风险，0 正常，1 提醒，2 红色 |
| `RISK` | 总风险，取 `R5` 和 `R7` 较高值 |
| `PLAN` | 计划类型 |
| `UP` | 本次更新时间 |
| `IP` | ESP32 IP |

| ID | 用途 |
| --- | --- |
| 20 | 顶部状态文本 |
| 21 | 5 小时剩余百分比 |
| 22 | 5 小时已用百分比 |
| 23 | 5 小时重置倒计时 |
| 24 | 5 小时重置时间 |
| 25 | 7 天剩余百分比 |
| 26 | 7 天已用百分比 |
| 27 | 7 天重置倒计时 |
| 28 | 7 天重置时间 |
| 29 | 7 天额度已用条形进度 |
| 30 | 7 天时间已过条形进度 |
| 31 | 7 天安全上限条形进度 |
| 32 | 7 天状态 |
| 33 | 7 天提示 |
| 34 | 计划类型 |
| 35 | 本次更新时间 |
| 36 | ESP32 IP |
| 37 | 日均消耗速率 |

| 41 | 最近一帧调试文本 |
